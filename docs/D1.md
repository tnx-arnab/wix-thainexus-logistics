# D1 setup (Wix)

Database lives on Cloudflare account **point@thainexus.co.th** (`60982be87817726f0bbc988e9122e2b7`).

## 1. Create database

The API token in `.dev.vars` must include **D1:Edit** (the default "Edit Cloudflare Workers" template does not). Then:

```bash
npx wrangler d1 create thai-nexus-wix --location apac
```

Paste the returned `database_id` into `wrangler.jsonc` `d1_databases[0].database_id`.

## 2. Apply schema

```bash
npx wrangler d1 migrations apply thai-nexus-wix --local
npx wrangler d1 migrations apply thai-nexus-wix --remote
```

Tables (tenant key = `instance_id`):

- `stores` - Wix OAuth access + refresh tokens (encrypted)
- `store_users` - optional user mapping
- `thai_nexus_config` - encrypted API token, shipper, boxes, fees (JSON text)
- `order_shipments` - auto-shipment refs
- `debug_logs` - rate traces / install / SPI events (`kind` generated from JSON)
- `install_logs` - kept for GDPR redact
- `product_flags` - document / boxed / eligible / `physical_override`

## 3. Local

```bash
npm run dev
```

API is Wrangler on `http://localhost:8787` (Vite proxies `/api`, `/health`, `/v1`).

## 4. Verify

```bash
curl -s https://wix.thainexus.co.th/health
# expect: { "ok": true, "d1": { "ok": true } }
```

After first install, `stores` should have one row per Wix instance:

```bash
npx wrangler d1 execute thai-nexus-wix --remote --command "SELECT instance_id FROM stores"
```

## 5. Production smoke

```bash
npx wrangler whoami
npx wrangler d1 list
curl -s https://wix.thainexus.co.th/health
# expect d1.ok true
curl -s https://wix.thainexus.co.th/api/setup
# expect checks.d1_ok true, no supabase_* keys
npx wrangler secret list
# no SUPABASE_* names
```

Then in Wix: dashboard opens, Settings save token + shipper, Products save flags + physical override, checkout quotes, paid order writes `order_shipments`.
